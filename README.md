# Колледж.Банк

**Практическая работа №3** по дисциплине «Проектирование веб-приложений».
Тема: «Реализация регистрации и авторизации».

Колледж.Банк — веб-сервис обмена навыками и помощью между студентами колледжа. В этой работе реализован модуль регистрации и авторизации пользователей.

## Что реализовано

- регистрация по трём полям: имя, электронная почта, пароль;
- проверка данных на сервере и запрет повторной регистрации одного адреса электронной почты;
- хранение паролей только в виде хеша (`password_hash` / `password_verify`);
- вход по электронной почте и паролю, сохранение входа в сессии PHP;
- страница личного кабинета (заглушка), доступная только после входа;
- безопасный выход из аккаунта (только POST-запрос с проверкой токена);
- три роли: гость, пользователь и автор (роль определяется автоматически по таблице `offers`);
- защита: подготовленные запросы PDO (SQL-инъекции), экранирование вывода (XSS), CSRF-токены, обновление идентификатора сессии после входа;
- тёмная и светлая темы с переключателем, плавные анимации.

## Стек

PHP, HTML, CSS, SQLite. JavaScript используется только для оформления.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.php` | главная страница |
| `register.php` | регистрация |
| `login.php` | вход |
| `dashboard.php` | личный кабинет (заглушка) |
| `logout.php` | выход из аккаунта |
| `theme.php` | сохранение выбранной темы |
| `style.css` | оформление |
| `config.php` | настройка сессии, подключение SQLite, создание таблиц |
| `functions.php` | общие функции: защита форм, проверка входа, роли |
| `layout.php` | шапка страницы и элементы форм |
| `hero_art.php` | декоративный элемент главной страницы |
| `bootstrap.php` | подключение общих файлов |
| `router.php` | запрещает открывать базу данных по адресу сайта |

## Как запустить

Требования: PHP 8.1 или новее с расширениями `pdo_sqlite` и `sqlite3`.

1. Скачайте репозиторий и откройте папку проекта в терминале.
2. Запустите встроенный сервер:

   ```
   php -S localhost:8000 router.php
   ```

3. Откройте в браузере http://localhost:8000

База данных SQLite создаётся автоматически при первом обращении, в папке `data`.
